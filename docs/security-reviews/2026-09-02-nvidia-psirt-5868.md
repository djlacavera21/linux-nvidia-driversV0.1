## nvlx scope assessment

`nvlx` does not install, package, configure, or operate Megatron Bridge. The
delta does not add or change a bulletin for the managed NVIDIA GPU Display
Driver, GPU Operator, DCGM/DCGM Exporter, Fabric Manager/Unified Fabric
Manager, NVSDM, NVSwitch, or NVOS surfaces. No driver or managed-component
minimum-version change is required.

The scheduled gate originally stopped because it searched the entire modified
cumulative 2026 indexes, which still contain older entries for managed
components. The accompanying monitor hardening restricts aggregate-index
matching to added and removed lines while retaining full-document inspection
for dedicated bulletin files and fail-closed behavior when the comparison
cannot be evaluated completely.
